读图顺序

1. 先看总量 窗口内 total tokens 是否突然变大。
2. 再看构成 cached input 高，说明长上下文在反复复用。
3. 对齐限额 用 reset 时间匹配 Settings 里的 weekly 窗口。
4. 找异常 session 大部分异常都能落到一个长任务上。

窗口趋势和限额

案例 A：日常使用

token 量低，output 占比小，weekly 几乎不动。适合每日汇总或每天固定一次。

案例 B：长任务异常

cached input 极高，说明大量上下文被反复带入。需要看 hot session 找到具体任务。

案例 C：费用拆分
